# Инструкция по работе с GREEN-API Chat (MAX)

## 1. О приложении

Веб-клиент для обмена текстовыми сообщениями через мессенджер **MAX** с использованием **GREEN-API**. Интерфейс приближен к оригинальному веб-клиенту MAX.

**Ключевые возможности:**

- Авторизация по данным инстанса GREEN-API
- Вход по QR-коду (для неавторизованных инстансов)
- Отправка и получение текстовых сообщений
- Список чатов, поиск, закрепление, контекстные меню
- Светлая / тёмная / системная темы

## 2. Требования

- **Node.js** 20+
- **npm** 10+
- Аккаунт в [GREEN-API](https://console.green-api.com)
- Приложение **MAX** на телефоне (для QR-авторизации и отправки/получения)

## 3. Локальный запуск

```bash
git clone https://github.com/7Hunter7/green-api-chat-max.git
cd green-api-chat-max
npm install
cp .env.example .env
npm run dev
```

Откроется: **http://localhost:5173**

**Production-версия (Vercel):** [https://chat-max-roan.vercel.app/](https://chat-max-roan.vercel.app/)

## 4. Получение данных инстанса GREEN-API

### Шаг 1. Регистрация / вход

1. Перейди на [console.green-api.com](https://console.green-api.com).
2. Зарегистрируйся (или войди, если уже есть аккаунт).

### Шаг 2. Создание инстанса

1. В личном кабинете нажми **«Создать инстанс»**.
2. Выбери тип **MAX**.
3. Выбери тариф:
   - **Developer** — бесплатно, ограничения (например, 3 чата в месяц).
   - **Business** — платный, без ограничений.
4. Дождись создания инстанса.

### Шаг 3. Копирование данных

На странице инстанса в личном кабинете скопируй **два параметра**:

| Параметр           | Пример               | Что это                |
| ------------------ | -------------------- | ---------------------- |
| `idInstance`       | `310022752482`       | Идентификатор инстанса |
| `apiTokenInstance` | `bde035edae3fc00...` | Ключ доступа           |

**Сохрани их** — без них в приложение не войти.

## 5. Авторизация в приложении

### Шаг 1. Первый экран

При открытии приложения появляется экран **выбора способа входа**:

- **Войти по QR-коду** — для привязки MAX-аккаунта к инстансу.
- **Войти по данным GREEN-API** — для существующего авторизованного инстанса.

### Шаг 2. Проверка состояния инстанса

Приложение автоматически запрашивает состояние инстанса через метод `getStateInstance`:

| Состояние         | Что значит                      | Что делать           |
| ----------------- | ------------------------------- | -------------------- |
| `authorized`      | Инстанс авторизован, всё готово | Переход в чат        |
| `notAuthorized`   | Аккаунт MAX не привязан         | **QR-авторизация**   |
| `pendingPassword` | Включён 2FA                     | **Ввод пароля**      |
| `starting`        | Идёт запуск инстанса            | Подожди 1–5 минут    |
| `blocked`         | Аккаунт заблокирован            | Обратись в поддержку |

### Шаг 3. Вход по QR-коду

Если инстанс **не авторизован**:

1. На экране появится **QR-код** (обновляется каждые 5 секунд).
2. На телефоне открой **MAX**.
3. **Настройки → Устройства → Подключить устройство**.
4. Наведи камеру на QR-код.
5. После успешного сканирования — приложение **автоматически** перейдёт в чат.

> **Важно!** Для входа по QR-коду нужно **отключить пароль входа** в MAX. Если пароль включён — перейди к следующему шагу.

### Шаг 4. Ввод пароля 2FA

Если при авторизации появился запрос пароля:

1. Введи **пароль двухфакторной аутентификации**, установленный в MAX.
2. Нажми **«Продолжить»**.

Возможные ошибки:

- **«Неверный пароль»** — проверь пароль.
- **«Слишком много попыток»** — подожди несколько минут.
- **«Сначала отсканируйте QR»** — вернись на шаг 3.

### Шаг 5. Восстановление сессии

При следующем открытии приложения авторизация **восстановится автоматически** из `localStorage`. Если инстанс был разлогинен — придётся войти заново.

## 6. Создание чата

### Через кнопку «+»

1. В **сайдбаре** нажми **«+»** (правый верхний угол заголовка «Чаты»).
2. Откроется меню:
   - Создать группу
   - Создать канал
   - Создать групповой звонок
   - **Найти по номеру**
   - Пригласить по ссылке
3. Выбери **«Найти по номеру»**.

> **Примечание:** на текущий момент **реально работает только «Найти по номеру»**. Остальные пункты — заглушки.

### Модальное окно «Найти по номеру»

1. Введи номер получателя в формате `9991234567` (префикс `+7` фиксирован для РФ).
2. Как только введёшь **10 цифр**, кнопка **«Найти в MAX»** станет активной.
3. Нажми кнопку.
4. Если номер зарегистрирован в MAX — чат появится в списке и откроется автоматически.
5. Если нет — появится ошибка **«На этом номере нет аккаунта MAX»**.

## 7. Работа с чатами

### Список чатов

Каждая карточка содержит:

- **Аватар** — инициалы из номера.
- **Имя** — номер или имя собеседника.
- **Превью** — последнее сообщение.
- **Время** — последнее сообщение.
- **Бейдж** — количество непрочитанных.
- **Пин** — если чат закреплён.

### Поиск по чатам

1. Введи текст в поле **«Найти»** в сайдбаре.
2. Поиск идёт по **имени** и **превью последнего сообщения**.
3. Для очистки — нажми **«×»** справа в поле.

### Контекстное меню чата

Наведи курсор на карточку → появится **«⋮»** в правом верхнем углу. Клик — меню:

| Пункт                                    | Что делает                                                |
| ---------------------------------------- | --------------------------------------------------------- |
| **Добавить в папку**                     | Заглушка (подменю: Новые / Каналы / Создать папку)        |
| **Открыть**                              | Открывает чат                                             |
| **Отметить прочитанным / непрочитанным** | Переключает состояние бейджа                              |
| **Отключить уведомления**                | Заглушка (подменю: На 1 час / 4 часа / 1 день / Навсегда) |
| **Стереть переписку**                    | Удаляет историю сообщений, чат остаётся                   |
| **Скрыть истории автора**                | Заглушка                                                  |
| **Заблокировать**                        | Заглушка                                                  |
| **Удалить чат**                          | Удаляет чат из списка                                     |

### Закрепление чата

Пункт **«Закрепить»** в контекстном меню:

- Чат поднимается наверх.
- В карточке появляется **иконка пина**.
- Пункт меню меняется на **«Открепить»**.

### Отметка прочитанным / непрочитанным

В зависимости от состояния:

- Если `unreadCount = 0` → **«Отметить непрочитанными»** (ставит бейдж `1`).
- Если `unreadCount > 0` → **«Отметить прочитанными»** (убирает бейдж).

## 8. Отправка и получение сообщений

### Отправка

1. Открой чат.
2. Введи текст в поле **«Сообщение»** внизу.
3. Нажми **Enter** (или кнопку отправки).

**Статусы сообщения:**

| Иконка         | Статус      | Что значит      |
| -------------- | ----------- | --------------- |
| `...`          | `pending`   | Отправляется    |
| `✓`            | `sent`      | Отправлено      |
| `✓✓`           | `delivered` | Доставлено      |
| `✓✓` (голубые) | `read`      | Прочитано       |
| `✕`            | `failed`    | Ошибка отправки |

### Ответы через консоль GREEN-API

Отвечать на входящие сообщения можно через **личный кабинет GREEN-API**:

### Шаг 1. Открыть консоль инстанса

1. Перейди в личный кабинет: [console.green-api.com](https://console.green-api.com).
2. Войди в аккаунт.
3. Открой **свой инстанс** — URL вида:

```
https://console.green-api.com/instanceList/{idInstance}
```

Например: [https://console.green-api.com/instanceList/310022752482](https://console.green-api.com/instanceList/310022752482)

### Шаг 2. Открыть раздел «Чаты»

1. В правой части страницы найди блок **«Чаты»**.
2. Нажми **«Открыть чаты»** — откроется встроенный чат-интерфейс:

- **Слева** — список чатов инстанса.
- **Под ним** — панель отправки:
- Поле выбора **Идентификатор чата** / **Номер телефона**.
- Поле ввода **«Номер телефона»**.
- Поле **«Введите сообщение»**.
- Кнопка **отправки**.

### Шаг 3. Отправить сообщение

1. **Выбери чат** в списке чатов.
2. **Или введи номер вручную** в формате `7XXXXXXXXXX` (например, `79991234567`).
3. Введи текст сообщения в поле **«Введите сообщение»**.
4. Нажми **кнопку отправки**.

**Ответ сервера:** если сообщение отправлено — оно появится в чате у получателя. Если ошибка — появится **под полем ввода**.

### Возможные ошибки

| Ошибка                                                | Причина                                                  | Решение                                                   |
| ----------------------------------------------------- | -------------------------------------------------------- | --------------------------------------------------------- |
| **«Превышена квота тарифа. Сообщение не отправлено»** | На тарифе **Developer** лимит (например, 3 чата в месяц) | Перейди на тариф **Business** в личном кабинете GREEN-API |
| **«Инстанс не авторизован»**                          | Аккаунт MAX не привязан к инстансу                       | Войди по QR-коду (см. раздел 5)                           |
| **«Ваш аккаунт временно ограничен»**                  | MAX ограничил отправку                                   | Отправляй только контактам, сохранившим твой номер        |

> **Важно:** polling работает **только при открытой вкладке**. Если закрыть браузер — сообщения не придут до следующего открытия.

## 9. Работа с окном чата

### Хедер чата

- **Кнопка «← Назад»** — закрывает чат (возвращает в состояние «чат не выбран»).
- **Аватар + имя + статус** — клик открывает профиль (заглушка).
- **Лупа** — открывает панель поиска.
- **«⋮»** — открывает меню:
  - **Отключить уведомления** (подменю: На 1 час / 4 часа / 1 день / Навсегда)
  - **Добавить в папку** (подменю: Новые / Каналы / Создать папку)

### Поиск по сообщениям

1. Клик по **лупе** в хедере → панель плавно **выезжает** под хедером.
2. Введи текст в поле **«Поиск»**.
3. Для закрытия — кнопка **«Закрыть»** или повторный клик по лупе.

> **Примечание:** панель поиска **открывается и закрывается**, но **фильтрация сообщений пока не подключена**.

## 10. Смена темы

### Где находится переключатель

1. В **узкой колонке навигации слева** (76px) внизу — кнопка **«Настройки»**.
2. Клик → открывается меню **справа** от кнопки.
3. Пункт **«Тема»** → **подменю**:
   - **Системная** — автоматически под ОС.
   - **Светлая** — всегда светлая.
   - **Тёмная** — всегда тёмная.

### Как это работает

- Текущая тема помечена **галочкой**.
- Выбор сохраняется в **`localStorage`** (`green-api-chat-theme`).
- При перезагрузке страницы тема **применяется мгновенно** (без «вспышки»).
- В режиме **«Системная»** — тема следует за настройкой ОС **в реальном времени** (без перезагрузки).

### Смена вручную через DevTools (опционально)

Открой консоль браузера:

```js
// Светлая
document.documentElement.dataset.colorScheme = "light";

// Тёмная
document.documentElement.dataset.colorScheme = "dark";
```

## 11. Выход из аккаунта

1. Кнопка **«Настройки»** в левой колонке.
2. Пункт **«Выйти»**.
3. Приложение вернётся на экран входа, `localStorage` очистится.

## 12. Частые вопросы

### «Инстанс не авторизован»

- **Причина:** нет привязанного аккаунта MAX.
- **Решение:** войди по QR-коду.

### «Превышен лимит тарифа Разработчик»

- **Причина:** на бесплатном тарифе — ограничение (например, 3 чата в месяц).
- **Решение:** перейди на тариф Business в личном кабинете GREEN-API.

### «Ваш аккаунт временно ограничен»

- **Причина:** MAX ограничил отправку сообщений.
- **Решение:** отправляй только контактам, которые сохранили твой номер; дождись окончания ограничения.

### Сообщения не приходят

- Проверь, что **вкладка открыта**.
- Проверь, что инстанс **авторизован** (см. лог консоли).
- Перезагрузи страницу.

### Тема не сохраняется

- Проверь, что в браузере **не отключён `localStorage`**.
- Проверь, что `localStorage` не заполнен (не переполнен).

### QR-код не отображается

- Инстанс **уже авторизован** — QR не нужен.
- Или отключи **пароль входа** в MAX для авторизации по QR.

## 13. Технические ограничения

- Polling работает **только при открытой вкладке**.
- История и список чатов хранятся **в `localStorage`**, не на сервере.
- Работает **только с текстом** (без медиафайлов).
- **Формат номера** — только РФ (`+7`).
- **Часть пунктов меню — заглушки** (уведомления, папки, блокировки). Это связано с отсутствием соответствующих методов в GREEN-API для MAX.
