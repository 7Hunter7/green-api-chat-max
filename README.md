# GREEN-API Chat (MAX)

Тестовое задание на позицию Frontend React-разработчик.

Минимальный интерфейс для отправки и получения текстовых сообщений через GREEN-API мессенджера MAX.

## Демо

- **Production (Vercel):** [https://chat-max-roan.vercel.app/](https://chat-max-roan.vercel.app/)
- **Локальный запуск:** [http://localhost:5173](http://localhost:5173)

## Документация
- [Инструкция по работе с приложением](docs/USAGE.md) — от авторизации в GREEN-API до смены темы

## Стек

- **React 19** + **TypeScript** — UI и типизация
- **Vite** — сборка и dev-сервер
- **CSS-переменные** — темизация без UI-библиотек
- **GREEN-API HTTP API** — транспорт сообщений
- **Polling** через `receiveNotification` + `deleteNotification` — получение входящих

Без Redux, без Router, без UI-китов.

## Функционал

### Авторизация

- Вход по `idInstance` + `apiTokenInstance`
- Вход по QR-коду с автообновлением (для неавторизованных инстансов)
- Поддержка 2FA (`pendingPassword` → `SendAuthorizationPassword`)
- Автовосстановление сессии из `localStorage`

### Чаты

- Список чатов с сохранением в `localStorage`
- Создание чата по номеру телефона через модальное окно «Найти по номеру»
- Поиск по чатам (по имени и превью последнего сообщения)
- **Контекстное меню чата:** добавить в папку, открыть, отметить прочитанным/непрочитанным, отключить уведомления, стереть переписку, скрыть истории автора, заблокировать, удалить
- **Закрепление чатов:** закреплённые поднимаются наверх, показывается иконка пина
- **Индикатор непрочитанных** сообщений с бейджем

### Сообщения

- Отправка сообщений (`SendMessage`) с оптимистичным UI
- Получение сообщений (polling каждые 1.5 сек)
- Индикаторы статуса: `pending` / `sent` / `delivered` / `read` / `failed`
- Автоматическая прокрутка к последнему сообщению

### Окно чата

- **Хедер чата** с аватаром, именем и статусом собеседника
- **Меню хедера:** отключить уведомления (на 1 час / 4 часа / 1 день / навсегда), добавить в папку
- **Поиск сообщений** — плавно выезжающая панель под хедером
- **Кнопка «Назад»** — закрывает текущий чат

### UI / UX

- **Трёхколоночный layout** как в веб-клиенте MAX: узкая навигация (76px) + сайдбар чатов + окно чата
- **Три режима темы** — «Системная», «Светлая», «Тёмная». Переключатель в меню «Настройки»
- **Фон чата с паттерном** — трёхслойный: градиент + radial-подсветки + SVG-паттерн с вуалью
- **Дизайн-система** на CSS-переменных: `Button`, `Input`, `Icon`, `Menu`, `MenuItem`, `Modal`, `NavButton`
- Адаптация под веб-клиент MAX: анимации, hover-состояния, контекстные меню

### Темизация

- **Три режима:** «Системная» (по умолчанию), «Светлая», «Тёмная»
- **Переключатель:** меню «Настройки» → «Тема» в узкой колонке навигации
- **Хранение:** `localStorage` (`green-api-chat-theme`)
- **Применение:** `data-color-scheme="light"|"dark"` на `<html>`
- **Без flash:** тема устанавливается инлайн-скриптом в `index.html` до первого рендера React
- **Живое обновление** при `mode === 'system'` — слушатель `prefers-color-scheme` меняет тему без перезагрузки

```bash
cd green-api-chat

npm run dev
```

Откроется `http://localhost:5173`.

## Использование

1. Получите данные инстанса в [console.green-api.com](https://console.green-api.com).
2. Введите в форму:
   - `idInstance` — например `310022752482`
   - `apiTokenInstance` — токен инстанса
3. Если инстанс не авторизован — появится QR-код. Отсканируйте в приложении MAX:
   **Настройки → Устройства → Подключить устройство**.
4. Если включён 2FA — введите пароль.
5. Нажмите **«+»** в сайдбаре и выберите **«Найти по номеру»**. Введите номер получателя в формате `9991234567` (поле `+7` — фиксированный префикс РФ).
6. Пишите сообщения.
7. **Смена темы:** «Настройки» в левой колонке → «Тема» → выбрать «Системная», «Светлая» или «Тёмная». Выбор сохраняется в браузере.

## Особенности реализации

- **Polling, не WebSocket.** Для тестового задания — проще и достаточно. В реальном продакшене был бы вебхук.
- **Рекурсивный `setTimeout`, не `setInterval`** — предотвращает наложение запросов при медленной сети.
- **`deleteNotification` обязателен** — без него сервер GREEN-API не отдаёт следующее уведомление.
- **Оптимистичный UI** — сообщение появляется сразу, потом заменяется серверным `idMessage`.
- **Portal для меню и модалок** — контекстные меню и модальные окна рендерятся в `document.body`, что избавляет от конфликтов `overflow: hidden` и `z-index` родительских элементов.
- **Дизайн-система на CSS-переменных** — все компоненты используют токены из `tokens.css`. Смена темы — через атрибуты `data-color-theme` и `data-color-scheme` на `<html>`.
- **React Context для вложенных меню** — `Menu` и `MenuItem` используют `MenuContext` для согласования открытия подменю (только одно открыто одновременно) и закрытия всей цепочки.
- **Темизация без UI-библиотек.** Тема управляется через CSS-переменные `tokens.css` и атрибуты `data-color-theme` / `data-color-scheme` на `<html>`. Все компоненты используют токены. Смена темы — мгновенная, без перерисовки React-дерева. Защита от flash — инлайн-скрипт в `index.html`.

## Ограничения

- Polling работает только при открытой вкладке.
- История сообщений и список чатов хранятся в `localStorage` браузера, не на сервере.
- Работает только с текстовыми сообщениями (по условиям задания).
- **Часть пунктов контекстных меню — заглушки:** «Добавить в папку», «Отключить уведомления», «Скрыть истории автора», «Заблокировать», «Создать группу / канал / звонок», «Пригласить по ссылке». Эти действия не имеют соответствующих методов в GREEN-API для MAX и показывают `alert` для демонстрации UI.
- **Реально работающие действия:** открыть чат, закрепить/открепить, отметить прочитанным/непрочитанным, стереть переписку, удалить чат.
- **Поиск сообщений** — реализован UI панели поиска (плавное появление под хедером), но **фильтрация сообщений пока не подключена**.
- **Формат номера** — только РФ (`+7`).
